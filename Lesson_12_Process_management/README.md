# Занятие 12. Управление процессами

## **Цель:**
- Научиться анализировать состояние процессов и управлять их выполнением.

### **Вариант 1. Реализация аналога ps ax**

- Создайте скрипт, который получает информацию о процессах через файловую систему /proc.
- Реализуйте вывод не менее следующих полей: PID, PPID, состояние процесса, имя или команда запуска.
- Проверьте работу скрипта на запущенной системе.
- Зафиксируйте пример результата работы.

### Выполнение
Для формирования данных напишем следующий скрипт my_ps_aux.sh, который получит имя, состояние, номер процесса и номер родительского процесса для каждого процесса из файла /proc/номер_процесса/status и запишет эти данные в промежуточный (временный) файл:
```
#!/bin/bash

# Формирование списка PID отсортированных в порядке возрастания
processes=($(ls -1 /proc | grep -Ew '[0-9]+' | sort -n))

# Проверка существования директории процесса и формирование файла с данными о процессах
processes_data=${HOME}/proccesses_data.txt

rm ${processes_data}
touch ${processes_data}

for i in "${processes[@]}"; do
  if [ -f "/proc/$i/status" ]; then
     grep -E '^Name:|^State:|^Pid:|^PPid:' /proc/$i/status 2>/dev/null | xargs >> ${processes_data}  
  else
   :
  fi 
done

# Форматирование итогового файла с данными о процессах (заголовоки и отступы)
awk 'BEGIN {
    printf "\033[1m%-40s %-40s %-40s %-40s\033[0m\n", "Name", "State", "Pid", "PPid"
} {
    printf "%-40s %-40s %-40s %-40d\n", $2, $5, $7, $9}' $processes_data
```
Чтобы придать скрипту вид работы в реальном времени, передадим его запуск утилите watch c интервалом запуска 1 раз в секунду:
```
watch -n1 './my_ps_aux.sh'
```
